\chapter{Conclusiones}

El desarrollo de este trabajo práctico permitió consolidar de manera práctica y analítica el diseño de automatismos
mediante lógica programada en controladores lógicos programables (PLC).

A lo largo del documento se demostró cómo las funciones lógicas básicas y las estructuras fundamentales de control
(autoenclavamiento, retardo a la conexión/desconexión y contadores) constituyen el pilar para la resolución de
problemas complejos de ingeniería como el control de bombas de agua con protección, montacargas, ascensores multinivel y
sistemas de señalización vial.
