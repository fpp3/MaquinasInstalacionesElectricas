\chapter{Introducción}

\section{Objetivos}
El objetivo fundamental de este trabajo práctico es desarrollar habilidades en la programación y simulación de
controladores lógicos programables (PLC) empleando el lenguaje de contactos o diagrama Ladder (LDR). A través de la
resolución de una serie de ejercicios de entrenamiento, se busca:

\begin{itemize}
    \item Implementar compuertas y operaciones lógicas elementales ($AND$, $OR$, $NOT$, $NAND$, $NOR$, $XOR$).
    \item Comprender y analizar circuitos de autoenclavamiento ($Start-Stop$) y comandos mediante temporizaciones e
    instrucciones Set/Reset.
    \item Implementar temporizadores y contadores para la automatización de procesos secuenciales y con control por tiempo.
    \item Desarrollar la lógica de control para aplicaciones industriales típicas como bombas de agua, montacargas,
    grúas industriales, control de ascensores y sistemas de semáforos interconectados.
\end{itemize}
